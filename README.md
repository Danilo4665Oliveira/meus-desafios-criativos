# meus-desafios-criativos
Atue como um especialista em educação financeira digital.

Crie a proposta de um Educador Financeiro Inteligente para jovens e adultos.

O sistema deve ajudar o usuário a observar e identificar gastos que impactam de forma agressiva renda mensal.

As principais funcionalidades devem incluir:
- Painel claro e intuitivo
- Porcentagem da renda mensal que já foi gasta
- Alertas a partir de % antigidas

A comunicação deve ser amigável e objetivo.

As respostas devem seguir o formato uma conversa de um profissional com um amigo.

Evite termos técnicos ou informações muito complexas.

Ao final, apresente sugestões criativas para transformar essa ideia em um projeto frontend interativo.
